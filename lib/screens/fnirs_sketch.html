Transmission fNIRS — Equipment & Setup Diagrams
Sketch 1 — Single Path Bench Test (Milk Phantom)
Goal: See a cross-correlation peak at all. If peak shifts when you change milk %, physics is working.
Key correction from Prof. Hansma (Mar 9): Chirp must reach MHz–GHz range — a 20–30 cm head = ~1 ns transit time, so the chirp period needs to be ~1 ns to tell direct photons from scattered ones.
Hardware needed: GHz-capable laser diode (telecom grade) · fast SiPM or avalanche photodiode · RF mixer or FPGA for correlation · 4× 9V batteries for clean detector bias
Sketch 2 — Ring Array (Tomographic Setup / Head from Above)
Each source fires a different chirp band so signals don't mix — code-division multiplexing.
All chords cross the rACC — that intersection is amplified, everything else averages out.
Back-projection math reconstructs which voxel changed (same algorithm as our simulation app).
Long-term goal: Patient sees real-time rACC activity → learns to lower it → chronic pain reduced. No fMRI needed.
